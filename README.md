# 🚀 Учебные веб-приложения на ASP.NET Core (C#)

В этом репозитории собраны два полноценных клиент-серверных веб-приложения, разработанных в рамках учебной практики. Оба проекта имеют современный адаптивный интерфейс, базу данных SQLite, JWT-авторизацию с разграничением ролей и интересные дополнительные фишки.

---

## 📂 Проект 1: «Ремонтная мастерская» (RepairShop)

Информационная система для автоматизации приёма и обработки заявок на ремонт бытовой и компьютерной техники. Система объединяет клиента, мастера и администратора в едином рабочем пространстве.

**✨ Ключевой функционал:**
* **Клиент:** просмотр каталога услуг, создание заявок с загрузкой фотографий неисправностей, отслеживание статуса ремонта (от «Принята» до «Выдана»).
* **Мастер:** рабочее место с назначенными заявками, смена статусов, добавление комментариев и списание запчастей со склада (с перерасчетом итоговой стоимости).
* **Администратор:** назначение мастеров на заявки, управление складом и каталогом услуг, просмотр аналитики (графики выручки, популярных поломок и загрузки мастеров).

## ☕ Проект 2: «Кофейня "Арабика"» (CoffeeShop)

Веб-приложение для заказа кофе и десертов с сильным акцентом на UI/UX-дизайн. Интерфейс выполнен в тёплой кофейной палитре, что создает уютную атмосферу для пользователя.

**✨ Ключевой функционал:**
* **Клиент:** интерактивный каталог товаров, корзина (с сохранением в браузере), оформление заказа, чтение блога кофейни и скачивание PDF-чеков с составом заказа.
* **Администратор:** управление товарами и статьями блога, просмотр статистики продаж, а также **интерактивная Kanban-доска заказов** с поддержкой перетаскивания карточек (Drag-and-Drop) для смены статусов.

---

## 🛠 Общий технологический стек

* **Backend:** C# 12, ASP.NET Core Web API (.NET 8)
* **База данных:** SQLite, Entity Framework Core (Code-First подход)
* **Frontend:** HTML5, CSS3 (Grid/Flexbox, кастомные кофейные стили), Vanilla JavaScript (Fetch API)
* **Сторонние библиотеки:** 
  * `BCrypt.Net-Next` (безопасное хеширование паролей)
  * `Microsoft.AspNetCore.Authentication.JwtBearer` (JWT-авторизация)
  * `QuestPDF` (динамическая генерация PDF-документов)
  * `Chart.js` (визуализация данных и статистики)
